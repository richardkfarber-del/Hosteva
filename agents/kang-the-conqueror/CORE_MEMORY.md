# Project Overview: Hosteva

## What is it?
Hosteva is the "Iron Man Suit" for short-term rental hosts. It is a web application designed to help property owners navigate the increasingly complex world of STR compliance, taxes, and listing requirements.

## The User Journey
1. **Eligibility Check:** The host provides their address. Hosteva cross-references our internal databases of Florida State, county, and local zoning laws to determine if they are eligible to operate a short-term rental at that location.
2. **Compliance Checklist (Paywall 1):** If eligible, we generate a personalized, prioritized, and itemized step-by-step compliance checklist. This is hidden behind the first paywall.
3. **Document Generation & Storage (Paywall 2):** Hosteva generates the actual documents they need to file, and stores/itemizes their documentation for easy access. This feature is behind a second paywall.
4. **Listing Syndication (Future Goal):** Eventually, users will be able to post their property on major short-term rental sites (Airbnb, VRBO) with the click of a button, for an additional fee.

## Current Focus
We are building the foundational infrastructure for the Eligibility Check and the first Stripe Paywall for the Compliance Checklist.
