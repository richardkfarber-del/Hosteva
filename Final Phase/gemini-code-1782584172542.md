# Technical Instructions for Antigravity: Interactive Upload Page & Gemini Auditor Connection

## 1. Frontend Routing & Event Interception
- **Action Link Modification:** Update the "Complete Now" button event handlers on `/dashboard?view=tasks` to intercept click events and perform a route transition to `/dashboard/tasks/:id` (where `:id` matches the `properties_compliance.id` key).
- **Component File:** Create a new React component at `src/components/compliance/TaskDetail.tsx` matching the design specified in Stitch's UI layout.

## 2. FastAPI Endpoints Integration
- **`GET /api/v1/compliance/tasks/{id}`**:
  - **Action:** Fetches the compliance item details from `properties_compliance`, retrieves associated county rules from the `MunicipalCode` table, and returns localized descriptions and "What to upload" text strings.
- **`POST /api/v1/compliance/tasks/{id}/upload`**:
  - **Payload:** `file: UploadFile` (Multipart Form-Data).
  - **Action:**
    1. Save the file binary locally or upload it to S3, and update `uploaded_file_url` in the database.
    2. Set `properties_compliance.status` to `'PENDING'`.
    3. Dispatch the Celery task `tasks.process_document_ocr` to process the document in the background.
- **WebSocket or Polling Handler (`GET /api/v1/compliance/tasks/{id}/status`)**:
  - Implement a simple polling or WebSocket route to notify the React frontend when the Celery task completes, prompting the UI to render the extracted parameters and compliance state changes.

## 3. Celery Task Extensions (`tasks.process_document_ocr` in `app/tasks/audit.py`)
- Configure the Gemini system prompt to dynamically adapt based on the `task_name` of the compliance record:
  - *If 'Pasco Conditional Use Permit task':* Prompt Gemini to extract the specific CUP permit number, expiration date, registrant name, and property parcel address.
  - *If 'Pasco 4% TDT registration':* Prompt Gemini to extract the 6-digit TDT account number and check if Pasco County is explicitly named as the authority.
  - *If 'State Sales Tax registration':* Prompt Gemini to extract the Florida DOR Certificate number and check for the combined 6.0% sales tax registration markers.

## 4. State Queue Transitions
- Bind the backend verification output directly to the frontend's visual alert states:
  - Return status `'APPROVED'` if the address and owner name matches (normalizing street suffixes via fuzzy comparison).
  - Return status `'PENDING_REVIEW'` if minor address variances are identified, allowing a manual admin override.
  - Return status `'REJECTED'` if a critical mismatch is found, logging the explicit reason inside `verification_notes` for the UI alert cards.
